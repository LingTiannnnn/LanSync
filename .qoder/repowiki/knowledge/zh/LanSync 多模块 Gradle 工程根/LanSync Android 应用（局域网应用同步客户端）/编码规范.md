- UI 状态统一通过 `MutableStateFlow` + `asStateFlow()` 暴露，ViewModel 用 `combine` 将多个 Repository StateFlow 合并到单一 `UiState` 数据类。
- 业务入口集中在 `LanSyncRepository` 门面类，按功能分组委托给 ConnectionCoordinator/UpdateCoordinator/DownloadInstallController 等协作者，自身不包含业务逻辑。
- 长耗时操作统一在 `viewModelScope.launch { withContext(Dispatchers.IO) { ... } }` 中执行，并通过 try/finally 重置 UI 标志位（如 isStarting/isStopping）。
- 用户可见文案一律通过 `getString(R.string.xxx)` 或 `stringResource` 读取，禁止硬编码字符串。
- data 层各子包以独立职责划分（connection/discovery/localapps/transfer/server/sync/packer/cache/model），并通过 `LanSyncGraph` 集中装配依赖。
- 日志统一经 `FileLogger.i/w/e(TAG, msg)` 输出，每个核心类定义私有 `TAG` 常量。
