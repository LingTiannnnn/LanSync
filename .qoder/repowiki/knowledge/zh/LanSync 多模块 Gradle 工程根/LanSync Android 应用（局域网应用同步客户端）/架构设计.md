模块遵循 MVVM + Repository 分层：`MainActivity` 通过 `LanSyncApp` 组合多个 Tab 页面（`DeviceListScreen`/`AppListScreen`/`RemoteAppListScreen`/`SyncScreen`/`FileListScreen`），UI 状态由 `MainViewModel` 暴露的 `UiState` StateFlow 驱动；ViewModel 仅持有 `LanSyncGraph` 获取的 `LanSyncRepository` 门面，所有业务逻辑委托给 data 层子包——`connection`（连接协调器+传输）、`discovery`（JmDNS 设备发现）、`localapps`（本地应用扫描）、`transfer`（打包/下载/安装）、`server`（Ktor 内嵌服务器）、`sync`（更新协调）、`packer`、`cache`、`model`。`ForegroundSyncService` 作为前台服务承载 `repository.start()/stop()` 生命周期，使服务端、设备发现与心跳在后台存活；`LanSyncApplication` 在进程启动时初始化 `FileLogger`。依赖方向严格单向：ui → viewmodel → repository → data/*，data 层不反向引用 ui。构建配置使用 AGP 8.13 + Kotlin 17 + Compose BOM 2023.10.01，网络栈为 OkHttp + Ktor Server (Netty) + JmDNS。
